# Proposal

## Why

도구 타임라인만 보면 모델에 몇 번 요청했는지, 각 응답이 어떤 도구 실행으로 이어졌는지 알기 어렵다. 사용자는 실행 중인 회차를 찾고 그 회차의 모델 출력을 읽으며 하네스의 동작을 따라가고 싶다.

## What Changes

- 모델 요청을 보낼 때마다 회차를 열고 응답 대기 상태를 표시한다.
- 회차마다 요청, 응답, 도구 호출과 결과를 한 줄의 다이어그램으로 연결한다.
- 응답 수신 후 해당 회차에서 모델의 텍스트와 도구 요청을 펼쳐 본다. 최종 답변은 기본으로 펼친다.

## Capabilities

### New Capabilities

- `model-rounds` — 모델 요청 단위의 상태, 출력과 후속 도구 실행을 함께 조회한다.

### Modified Capabilities

## Impact

기존 `visualize-agent-loop`의 실행 선택 및 타임라인 기록을 활용한다. worker의 요청 관측, 호스트의 실행 기록, 브라우저 뷰어와 키 없는 재현 실습이 영향을 받는다.
