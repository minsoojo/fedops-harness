## 검증 기록
브라우저 실행 ask-jx7bcc89에서 세 출처가 동시에 조사 중인 화면을 캡처하고 각 담당 완료와 채팅의 합성 답변을 확인했다. ask-yp2ga7cn에서는 docs만 선택되어 3회차에 완료됐다.
복합 질문의 첫 합성에 원문에 없는 인용이 있어 URL 검사를 추가했다. 최종 빌드의 라이브 재검증은 OpenRouter HTTP 429로 두 번 중단됐다. 같은 실제 모델 출력을 재생하여 브라우저에서 허위 경로 제거와 검증된 출처별 결과 표시를 확인했다.

OpenAI API로 전환한 뒤 같은 질문으로 실제 UI에서 재검증했다. 첫 실행(ask-mx20xnu6)에서 저장소 담당이 설정을 읽고도 구현 조사를 계속해 할당량을 소진했다. 설정 원문을 확인하면 답하도록 지침을 보강했다. ask-irnix3m4는 gpt-4.1-mini로 7회차에 완료됐다. 세 조사 세션의 공통 실행 구간은 2.85초였고 오류는 없었다. 채팅·타임라인의 최종 답변을 확인하고 FedOps 1.3 Overview, 고정 커밋 3cd08420의 CIFAR100 config.yaml 42–43행, Graphify의 weighted_average → Metrics 참조 및 aggregation.py 25행을 대조했다.
