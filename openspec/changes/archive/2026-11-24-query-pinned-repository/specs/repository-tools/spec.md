## Purpose

사용자가 FedOps 코드나 설정 위치를 물으면 에이전트가 실행 중에 정확한 심볼을 검색하고 고정된 원문을 다시 읽어 근거 있는 답변을 작성하도록 한다.

## ADDED Requirements

### Requirement: 실행 중 검색 및 읽기
에이전트는 고정 커밋의 Python 및 YAML 파일에 대해 오프라인으로 검색하고 찾은 경로의 줄 범위를 읽을 수 있어야 한다 (SHALL).

#### Scenario: 설정 출처 확인
- **WHEN** 에이전트가 weighted_average의 설정 위치를 검색하고 해당 파일을 읽는다
- **THEN** 도구는 같은 커밋의 config.yaml 원문을 반환하고 타임라인에는 검색과 읽기 호출이 기록된다.

#### Scenario: 입력과 미리보기
- **WHEN** 사용자가 같은 질문으로 근거를 미리 보고 작업을 시작한다
- **THEN** 미리보기에는 기존 저장소 검색 결과가 보이고 작업 입력에는 저장소 도구의 경로와 사용 방법이 제공된다.
