## Purpose

사용자가 브라우저에서 입력한 FedOps 질문으로 실제 ask 실행을 시작하고 해당 작업의 실시간 진행과 최종 답변을 같은 화면에서 확인하도록 한다.

## ADDED Requirements

### Requirement: 질문별 실행 추적
뷰어는 질문마다 고유한 ask 실행을 만들고 선택한 실행의 진행과 종료 결과를 보여야 한다 (SHALL).

#### Scenario: 질문 실행
- **WHEN** 사용자가 질문을 제출하고 다른 실행도 시작된다
- **THEN** 제출한 실행의 회차를 계속 표시하고 완료 시 해당 답변을 펼쳐 보인다.

#### Scenario: 실패
- **WHEN** 실행 중 샌드박스 또는 모델 호출이 실패한다
- **THEN** 해당 실행에 실패 상태를 표시하고 새 질문을 제출할 수 있다.
