## Purpose

사용자가 FedOps에 질문하면서 대화를 유지하고, 필요할 때 개별 실행의 타임라인이나 검증기 보호 실험, 저장소 코드 관계를 독립된 화면에서 확인할 수 있게 한다.

## ADDED Requirements

### Requirement: 하네스 화면 선택
뷰어는 채팅을 기본 화면으로 열고 왼쪽 메뉴에서 실행 타임라인, 검증기 보호 실험, Graphify 그래프로 이동할 수 있게 해야 한다 (SHALL).

#### Scenario: 첫 방문
- **WHEN** 사용자가 하네스의 기본 주소를 연다
- **THEN** 채팅에서 질문을 입력할 수 있으며 다른 패널은 메뉴에서 선택할 때 열린다.

#### Scenario: 실행 중 화면 전환
- **WHEN** 질문을 보낸 후 다른 탭을 열었다가 채팅으로 돌아온다
- **THEN** 기존 질문과 해당 실행의 진행 또는 답변이 대화에 남고 타임라인의 실행 선택도 유지된다.

### Requirement: 저장소 그래프 열람
Graphify 탭은 FedOps 코드에서 생성한 인터랙티브 커뮤니티 그래프를 로컬 자산으로 표시해야 한다 (SHALL).

#### Scenario: 그래프 직접 열기
- **WHEN** 사용자가 그래프 탭 또는 해당 탭의 주소를 연다
- **THEN** 코드 커뮤니티와 커뮤니티 간 연결을 표시하는 Graphify 캔버스를 볼 수 있다.
