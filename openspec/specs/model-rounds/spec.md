# model-rounds Specification

## Purpose

사용자가 실행 중인 에이전트가 모델 응답을 기다리는지 도구를 실행하는지 확인하고, 각 모델 응답을 그 응답에서 요청한 도구와 함께 다시 읽을 수 있게 한다.

## Requirements

### Requirement: 모델 요청마다 회차 시작
뷰어는 실행별로 첫 모델 요청을 1회차로 표시하고, 이후 모델 요청을 보낼 때마다 번호를 하나 올려야 한다 (SHALL).

#### Scenario: 응답을 기다리는 동안
- **WHEN** 실행의 첫 요청을 보냈고 응답 수신이 끝나지 않았다
- **THEN** 화면에 ‘1회차 · 모델 응답 대기 중’이 표시되고 부분 출력은 보이지 않는다.

#### Scenario: 도구 결과 이후 다음 요청
- **WHEN** 1회차의 도구 결과가 반환됐다
- **THEN** 결과는 1회차에 붙고, 다음 모델 요청을 보내는 순간 ‘2회차 · 모델 응답 대기 중’이 표시된다.

### Requirement: 회차별 도구 흐름
뷰어는 각 회차의 요청과 응답을 한 줄의 다이어그램으로 연결하고 응답에 딸린 각 도구의 이름, 실행 상태와 결과 반환 여부를 보여야 한다 (SHALL).

#### Scenario: 한 응답에서 두 도구 요청
- **WHEN** 한 응답이 두 Read 호출을 요청하고 두 번째 호출의 결과가 먼저 도착한다
- **THEN** 같은 회차의 응답에서 두 갈래가 이어지며, 결과가 도착한 호출만 반환으로 표시되고 나머지 호출은 진행 상태로 보인다.

### Requirement: 해당 회차에서 모델 출력 열람
사용자는 응답 수신이 끝난 회차에서 모델이 전달한 텍스트와 도구 요청의 이름 및 인자를 펼쳐 볼 수 있어야 한다 (SHALL).

#### Scenario: 도구 요청만 있는 응답
- **WHEN** 사용자가 설명 텍스트 없이 Edit를 요청한 응답을 펼친다
- **THEN** 해당 회차에 실제 Edit 요청과 인자가 표시된다.

#### Scenario: 텍스트와 도구가 함께 있는 응답
- **WHEN** 사용자가 설명과 도구 요청이 함께 있는 응답을 펼친다
- **THEN** 해당 응답의 텍스트와 요청이 모델이 보낸 순서대로 보이고 다른 회차의 출력은 섞이지 않는다.

#### Scenario: 최종 답변과 재조회
- **WHEN** 도구 요청이 없는 최종 답변으로 실행이 끝나고 사용자가 그 실행을 다시 연다
- **THEN** 마지막 회차에는 최종 답변이 기본으로 펼쳐지고, 앞선 회차의 출력도 개별적으로 열 수 있다.

#### Scenario: 응답 전 실패
- **WHEN** 모델 응답을 기다리다 실행이 실패한다
- **THEN** 진행 중이던 회차에서 실패가 표시되며 이미 받은 이전 회차의 출력은 계속 열 수 있다.
